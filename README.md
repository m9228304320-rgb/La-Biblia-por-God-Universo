## 🌌 Objetivo del Proyecto

El propósito de este repositorio es construir de forma colaborativa una base de conocimientos sobre las escrituras, comenzando desde el **Génesis** hasta el **Apocalipsis**, abarcando diferentes perspectivas teológicas y hermenéuticas.

**Nuestros objetivos específicos:**
- 📚 Recopilar textos bíblicos en múltiples versiones y idiomas
- 🔍 Proporcionar análisis profundos y comentarios sobre pasajes clave
- 🌍 Hacer las Sagradas Escrituras accesibles para todo el mundo
- 🤝 Fomentar el estudio colaborativo y respetuoso de la Biblia
- 📖 Crear recursos complementarios (mapas, glosarios, cronologías)

## 🚀 Cómo Contribuir

¡Cualquier persona del universo puede aportar a este repositorio! Si deseas colaborar:

### Pasos básicos:

1. **Fork** este repositorio
   ```bash
   git clone https://github.com/TU_USUARIO/La-Biblia-por-God-Universo.git
   cd La-Biblia-por-God-Universo
   ```

2. Crea una rama con tu aporte
   ```bash
   git checkout -b feature/tu-contribucion
   ```

3. Realiza tus cambios siguiendo las [Directrices de Contribución](#directrices-de-contribución)

4. Commits claros y descriptivos
   ```bash
   git commit -m "Agrega análisis del Génesis capítulo 1-3"
   git push origin feature/tu-contribucion
   ```

5. Abre un **Pull Request** para revisar e incorporar tus cambios
   - Describe brevemente tu contribución
   - Menciona qué sección mejoraste
   - Proporciona referencias de fuentes si es aplicable

## Directrices de Contribución

### 📝 Formato de Archivos
- Todos los archivos deben estar en formato **Markdown (.md)**
- Usa encabezados jerárquicos (H1 → H4)
- Mantén líneas de máximo 80 caracteres cuando sea posible
- Usa listas numeradas y con viñetas coherentemente

### 📚 Contenido
- **Citas bíblicas**: Siempre incluye la referencia (Libro, Capítulo:Verso)
- **Versiones**: Especifica qué versión de la Biblia usas (RVR60, LBLA, NVI, etc.)
- **Análisis**: Sé respetuoso con diferentes interpretaciones teológicas
- **Fuentes**: Cita tus fuentes cuando hagas afirmaciones académicas

### ✍️ Estilo
- Tono profesional pero accesible
- Evita lenguaje ofensivo o discriminatorio
- Sé inclusivo y respetuoso con todas las perspectivas cristianas

### 🔍 Ejemplos de Contribuciones

**Textos bíblicos anotados**
```markdown
# Génesis 1:1-5
Versión: RVR60

## Texto
En el principio creó Dios los cielos y la tierra...

## Análisis
[Tu análisis aquí]
```

**Resúmenes de libros**
```markdown
# Resumen: Libro de Job
- Autor: [Información]
- Período: [Año estimado]
- Tema principal: [Descripción]
```
